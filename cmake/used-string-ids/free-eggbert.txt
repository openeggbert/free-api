# Free Eggbert's actually-used LoadStringA/STRINGTABLE numeric IDs.
#
# Hand-maintained from direct source-code evidence in ../free-eggbert (see
# docs/used-string-ids.md for the full audit methodology and how this file
# is regenerated/re-verified). Every ID below is proven used by an actual
# LoadString(...) call site (LoadString is free-eggbert's own wrapper around
# LoadStringA, resolved via g_hInstance -- src/misc.cpp) or by an evidenced
# computed range. This is NOT the same as "every ID defined in resource.h":
# free-eggbert's resource.h defines many more IDs than the game actually
# loads through LoadString (364 STRINGTABLE entries exist; free-eggbert has
# 308 unique used string IDs, per this file, as of this audit).
#
# Format: one bare numeric ID per line, or an inclusive "A-B" range. Each ID
# must appear exactly once -- cmake/ExtractStringTable.cmake's USED_IDS_FILE
# fails CMake configure loudly if any ID (bare or via a range) repeats, since
# a duplicate would make the "N unique used string ID(s)" count misleading.
# If the same ID has more than one call-site citation, list it once with
# both citations in its comment (see e.g. IDs 194 and 288 below).
# '#' starts a comment; blank lines are ignored.
#
# Verified: cross-checked against a live extraction of resource/Eggbert2.rc
# -- every ID below is present in the extracted table (zero "used but not
# extracted" mismatches), and de-duplicated (308 unique used string IDs,
# matching the line above).
